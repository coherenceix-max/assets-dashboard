# assets-dashboard

GitHub Pages 로 배포되는 개인용 대시보드 모음입니다.

| 페이지 | 설명 |
| --- | --- |
| `index.html` | 부동산 갈아타기 자산 플랜 (수동 입력 기반) |
| `kospi.html` | **코스피 페어밸류 모니터** — 30분마다 자동 갱신되는 적정가치 스크리너 |

## 코스피 페어밸류 모니터

### 동작 구조

```
GitHub Actions (30분 주기)          GitHub Pages
scripts/fetch_kospi.py  ──▶  data/kospi.json  ──▶  kospi.html (브라우저에서 모델 계산)
        │                                              │
   KRX 정보데이터시스템                        30분 카운트다운 후 자동 재요청
```

- **수집**: `.github/workflows/kospi-data.yml` 이 평일 KST 09:00~16:30 사이 30분마다,
  그리고 18:00 마감 확정치로 한 번 더 실행됩니다.
  KRX 정보데이터시스템에서 코스피 전 종목의 시세·PER·PBR·EPS·BPS·DPS·배당수익률·업종을 받아
  `data/kospi.json` 으로 커밋합니다.
- **과거 분포**: `data/history.json` 에 월말 밸류에이션 스냅샷이 누적됩니다.
  최초 실행 시 과거 36개월을 자동 백필하며(`KOSPI_BACKFILL_MONTHS` 로 조정), 최대 48개월 보관합니다.
- **표시**: `kospi.html` 은 원자료만 받아 **브라우저에서 적정가치를 계산**합니다.
  덕분에 요구수익률·성장률 슬라이더를 움직이면 재수집 없이 즉시 재계산됩니다.

### 적정가치 4모델

| 모델 | 계산식 | 필요 데이터 |
| --- | --- | --- |
| 잔여이익(정당 PBR) | `(ROE − g) / (r − g) × BPS` | EPS, BPS |
| 그레이엄 수 | `√(22.5 × EPS × BPS)` | EPS>0, BPS>0 |
| 업종 상대가치 | `업종 중앙 PER × EPS`, `업종 중앙 PBR × BPS` 의 평균 | 업종 분류 |
| 과거 밴드 회귀 | `자기 과거 중앙 PER × EPS`, `중앙 PBR × BPS` 의 평균 | history.json |

기본값인 **종합**은 계산 가능한 모델들의 중앙값이며, 근거 모델이 2개 미만인 종목은 제외합니다.
`괴리율 = 적정가 ÷ 현재가 − 1` 로, (+)면 저평가·(−)면 고평가입니다.

### 처음 켤 때

1. 이 브랜치를 기본 브랜치(`main`)에 머지합니다.
   GitHub 은 **기본 브랜치에 있는 워크플로만** 스케줄·수동 실행합니다.
2. Actions 탭 → `KOSPI 페어밸류 데이터 수집` → **Run workflow** 로 첫 수집을 한 번 돌립니다.
   (과거 36개월 백필 때문에 첫 실행만 2~3분 걸립니다.)
3. `https://<사용자>.github.io/assets-dashboard/kospi.html` 접속.

### 알아둘 점

- 장중 시세는 KRX 공표 기준 **약 20분 지연**입니다.
- EPS·BPS 는 최근 확정 실적 기준이라 실적이 급변한 종목, 일회성 손익, 지주사·자산주에서는
  적정가가 왜곡될 수 있습니다. 스팩·리츠는 수집 단계에서 제외했습니다.
- 이 대시보드는 **참고 지표이며 매매 신호가 아닙니다.**
